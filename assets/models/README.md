# Preview fixture

`preview-torus.obj` is original TexUtil sample geometry, covered by the repository's
MIT license. Its matching `.mtl` identifies a body and a band for material-ID baking.
The torus has major radius 0.7, minor radius 0.27, 64x24 segments, Y-up orientation,
outward-facing triangles and a unique 0..1 UV layout. It is a test and demonstration
asset, not a required runtime dependency.
